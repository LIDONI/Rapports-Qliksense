# Rapports Data – Qlik Sense

Ce dépôt présente une série de dashboards analytiques développés avec Qlik Sense, illustrant des cas concrets de transformation, modélisation et valorisation de données dans une logique décisionnelle.

**Contexte**

Dans un environnement data-driven, la capacité à transformer des données brutes en indicateurs exploitables est essentielle.
Les projets présentés s’inscrivent dans cette démarche en proposant des applications interactives permettant d’explorer, analyser et piloter des données issues de sources multiples.

**Objectifs**

Concevoir des dashboards interactifs orientés métier
Transformer et structurer des données multi-sources
Mettre en œuvre des modèles de données performants (logique associative Qlik)
Faciliter la prise de décision via des visualisations claires et dynamiques

**Réalisations**

Développement d’applications analytiques complètes sous Qlik Sense
Intégration et préparation de données via scripts de chargement Qlik
Modélisation de données optimisée pour l’analyse (associative model)
Création de visualisations interactives (KPIs, filtres, drill-down, etc.)
Utilisation d’expressions avancées, variables et logiques conditionnelles
Structuration de dashboards orientés pilotage et suivi de performance

**Technologies**

Qlik Sense : développement de dashboards, modélisation et visualisation
SQL : extraction et structuration des données
Sources de données : fichiers plats, bases de données, APIs

**Approche**

Chaque projet suit une démarche complète :

- Ingestion et compréhension des données
- Nettoyage et transformation
- Modélisation des données
- Définition des KPIs métier
- Développement de dashboards interactifs
- Optimisation de l’expérience utilisateur (UX data)

**Données**

Dans une logique de respect des bonnes pratiques data, les jeux de données présentés dans ce dépôt sont entièrement non confidentiels.

Ils sont :

- anonymisés,
- synthétiques,
- ou issus de sources publiques.

Aucune donnée sensible ou propriétaire issue d’expériences professionnelles n’est exposée.
Ce dépôt a une vocation exclusivement démonstrative et pédagogique.

**À propos**

Ces projets mettent en avant une approche orientée data visualisation, qualité des données et aide à la décision, avec une attention particulière portée à la lisibilité, à la pertinence des indicateurs et à l’expérience utilisateur.
